# Utilities used in my SwayWM workflow
- `sway`: The Compositor
- `swayidle`: Provides screen locking
- `swaylock`: Provides idle hooks like lock, suspend, etc.
- `wofi`: Command Launcher, Application Launcher, Window Switcher. (kinda like rofi but lighter)
- `mako`: Notification daemon (single binary and configurable entirely via text)
- `clipman`: Clipboard history
- `grim` + `slurp`: Take screenshots + select region
- `swappy`: Annotate captured screenshots.
- `brightnessctl`: Control brightness 
- `foot`: Native wayland terminal. 
- `nmtui`: Terminal-based network management utility.
- `bluetui`: Terminal-based bluetooth manager

## Good to haves
- `btop`: Interactive CPU, Memory, disk and network monitor.
- `duf`: Human readable disk usage (better `df`). 
- `lnav`: Interactive log viewer for `journald` and files.
- `ripgrep`: Fast recursive search.
- `fzf`: Fuzzy selection
- `fd`: Better `find`
- `spf`: Superfile; Terminal-based file manager
